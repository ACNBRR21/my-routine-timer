📥 1. Download Blank CSV Schedule Template

Use this pre-formatted CSV template to draft your schedule offline in Microsoft Excel, Apple Numbers, or Google Sheets.

Standard Column Format:

Column Status Purpose
Routine Required Group name (e.g. Morning Block, Work Flow, Evening Routine).
Task Name Required Action title. Prepend ★ [Top Priority] for vital big rocks.
Duration (Mins) Required Target duration in minutes (e.g. 5, 25, 50). Use 0 for headers.
Parent Task Optional Category or project tag.
Scheduled Start For Anchors 24-hour time (e.g. 10:00, 14:30). Pinned calendar anchor meetings.
Notes Optional Task context, explanation, or sub-task notes (word-wrapped in timer).
